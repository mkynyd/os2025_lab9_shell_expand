## Lab9 工作内容概括（Shell 功能扩展）

在 Lab9 中，我主要完成了 **MiniEuler 内核 Shell 模块的功能扩展与完善工作**，目标是在 **QEMU 虚拟环境**下为系统提供一个可交互、可观测的调试入口。

### 1. 完成 Shell 基本交互框架的落地

基于原有的 Shell 任务框架，我完成并验证了以下基础能力：

-   Shell 以**独立内核任务**方式运行，启动后提供 `miniEuler #` 交互提示符
    
-   基于 **UART 中断 + 信号量同步** 的输入机制，实现字符级接收
    
-   使用环形缓冲区保存输入数据，Shell 任务通过 `sem_uart_rx` 同步读取
    
-   支持字符回显、回车提交命令
    

这部分工作确保 Shell 在 QEMU 的 `-nographic` 模式下能够稳定运行，成为系统的交互入口。

---

### 2. 实现命令分发表机制（可扩展设计）

相较于原始的硬编码命令判断方式，我采用了**命令表 + 函数指针**的方式组织 Shell 命令：

-   定义统一的 Shell 命令结构（命令名、说明、处理函数）
    
-   Shell 在运行时对输入命令进行解析并在命令表中匹配
    
-   新增命令只需注册到命令表中，无需修改主逻辑
    

这一设计使 Shell 具备良好的**可扩展性和可维护性**，为后续功能扩展打下基础。

---

### 3. 扩展并实现完整的 Shell 命令集

在 Lab9 中，我为 Shell 实现并验证了以下命令：

-   **help**：列出所有支持的 Shell 命令及功能说明
    
-   **ps**：显示当前系统任务快照（任务 ID、优先级、栈大小）
    
-   **top**：循环输出任务信息快照，用于观察任务状态变化
    
-   **tick**：显示当前系统 Tick 计数，验证定时器与时钟中断运行情况
    
-   **memstat**：显示内核镜像内存布局（text、rodata、data、bss、heap、system stack）
    
-   **semstat**：显示系统信号量使用情况（总数、已用、空闲及详细列表）
    
-   **quit**：提示 QEMU 正确退出方式
    

所有命令均在 QEMU 中成功运行并输出预期结果。

---

### 4. 新增信号量状态统计模块（自主扩展）

在原有代码基础上，我**新增了文件**：

```
lab9/src/kernel/sem/prt_sem_stat.c
```

在该文件中实现了：

-   对系统信号量控制块的遍历
    
-   统计信号量总数、已使用数、空闲数
    
-   输出每个已使用信号量的 ID、计数值和状态
    

并将其通过 `semstat` 命令接入 Shell，使信号量子系统具备**可观测能力**。  
这是 Lab9 中唯一新增的内核源文件，属于明确的功能扩展点。

### 5. 完善 Shell 可用性细节

为提升 Shell 的实际使用体验，我还完成了以下改进：

-   **退格键（Backspace）支持**：允许在命令行中删除已输入字符
    
-   输出格式对齐，保证命令结果在终端中清晰可读
    
-   处理未知命令时给出友好提示并引导使用 `help`
    

这些改动虽然规模不大，但显著提升了 Shell 的可交互性。

整个 Lab9 的设计、调试和验证均基于：

-   QEMU `virt` 平台
